Control API

One URL = one button. Drive StreamGraphics from Bitfocus Companion, a Stream Deck, or any automation — everything is addressed by the name you gave it in the app. In Companion, use a Generic HTTP Request action (method GET) and paste one of these URLs.
Using Bitfocus Companion? There's now a native StreamGraphics Pro module for it — add it as a connection, then drag ready-made buttons out of the Presets tab instead of pasting URLs. Buttons go red while a graphic is actually on the Program output, and live scores and the timer can sit right on the keys. See the online guide for it. The URL commands below still work, and remain the way to drive StreamGraphics from a Stream Deck on its own or from any other automation.
Opening this page from another computer? Use the show computer's network address above (e.g. http://192.168.1.50:4000) — that's what your Stream Deck / Companion machine must reach. Change it here and every URL below updates. Windows may prompt to allow network access the first time.
