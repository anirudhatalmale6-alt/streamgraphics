Mail-merge from a spreadsheet

In the Graphics Builder, name a text (or image) layer a "CSV field" — e.g. PlayerName. Then hit "Import CSV" on that graphic above; each row fills the fields and becomes a version you can step through (◀ ▶) or jump to by name. Great for rosters, speakers, graduations.

Fixing the sheet mid-event: hit ✎ Edit rows on any graphic that has a spreadsheet. Shorten a name that's running off the lower third, delete someone who scratched, add a late entry, or change the running order — while the show is live. Every change saves as you make it, and if you edit the entry that's currently on air the output updates straight away. There's a filter box for finding one person among hundreds, and an Undo if you delete the wrong row.

Program output for OBS / vMix / browser: http://THIS-PC-IP:PORT/program-output — shows every preset that's toggled ON, composited, transparent.
